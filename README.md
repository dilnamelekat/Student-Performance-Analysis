# Student Performance Analysis

## Project Overview

This project analyzes student performance data using Python.

The analysis includes:

- Data Exploration
- Score Analysis
- Subject Comparison
- Data Visualization
- Correlation Analysis

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset

Student Performance Dataset containing:

- Gender
- Reading Score
- Writing Score
- Math Score

---

## Project Tasks

### Data Cleaning

- Checked missing values
- Verified data types

### Data Analysis

- Average scores
- Highest and lowest scores
- Total marks calculation
- Percentage calculation

### Data Visualization

- Histogram
- Bar Chart
- Scatter Plot
- Correlation Heatmap

---

## Results

- Reading score achieved the highest average.
- Strong positive relationship between reading and writing scores.
- Performance trends were identified using visualizations.
